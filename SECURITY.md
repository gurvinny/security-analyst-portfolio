# Security Policy

## Reporting

This repository is documentation and published work, not deployed software. If you find a
security concern in what is published here — a credential, an exposed address, or a
misconfiguration presented as safe — contact me at the email address in the README.

Please do not open a public issue or pull request for a security concern. Issues are disabled on
this repository, and a public pull request would disclose the finding before it can be corrected.

## Scope

Findings that are in scope:

- Credentials, keys, or tokens committed to this repository
- Infrastructure detail published in error
- Guidance in the documentation that would leave a reader less secure if followed

Out of scope: the security of any third-party tool referenced here, and the configuration of
systems other than the ones documented in this repository.
