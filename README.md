## 🔬 Featured Projects

### 🏠 [Home Network Lab](https://github.com/gurvinny/home-network-lab)
Designed and deployed a segmented home lab environment to simulate enterprise network architecture and practice defensive security monitoring.
- **Objective:** Establish a secure, monitored environment for malware analysis and traffic inspection.
- **Key Technologies:** PfSense, VLANs, Snort/Suricata, Splunk Forwarder, Windows, Linux.
- **Outcome:** Successfully configured network segmentation (IoT, Guest, Lab) and implemented IDS/IPS rules to detect malicious traffic patterns. Gained hands-on experience routing traffic and analyzing logs.

### 🐬 [Flipper Zero Lab](https://github.com/gurvinny/grv-flipper-lab)
Exploration of hardware security and radio frequency (RF) protocols using the Flipper Zero multi-tool.
- **Objective:** Understand physical access control systems and wireless communication vulnerabilities.
- **Key Areas:** RFID/NFC cloning, Sub-GHz signal analysis, BadUSB scripting.
- **Outcome:** Demonstrated practical attacks on insecure access controls and documented mitigation strategies for RF-based threats.

## 📂 SOC Portfolio Modules

### 📘 [SOC Playbooks](soc-playbooks/)
Detailed incident response runbooks for common security alerts, following NIST guidelines. Showcases structural methodology for triage and containment.
- **Phishing Analysis:** Steps to analyze email headers, attachments, and URLs.
- **Malware Triage:** Procedures for static analysis and sandbox detonation.
- **Brute Force:** Detection and response workflows for failed login attempts.

### 🔍 [Detection Engineering](detections/)
Repository of custom detection rules and SIEM queries.
- **Sigma Rules:** Vendor-agnostic detection formats for various attack techniques.
- **Splunk/Elastic Queries:** Optimized search queries to hunt for indicators of compromise (IOCs).
- **MITRE ATT&CK Mapping:** Aligning detections with specific tactic and technique IDs.

### 🧪 [Lab Investigations](labs/)
Comprehensive writeups of attack simulations and CTF challenges.
- **TryHackMe Walkthroughs:** Walkthroughs focusing on the *defensive* perspective—analyzing the artifacts left behind by attacks.
- **Digital Forensics:** Timeline creation and evidence gathering from disk and memory images.
